How to upload to Netlify:

1. Open this folder.
2. Select these files/folders:
   - index.html
   - style.css
   - script.js
   - images
3. Zip them together so index.html is at the root of the ZIP.
4. Upload the ZIP to Netlify Drop.

Do not upload only the HTML file.
Do not put the folder inside another folder before zipping.
